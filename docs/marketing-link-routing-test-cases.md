# Social CTA link test cases

Use these checks before merging:

- NexDocs brief resolves `nexdocs` and copies `https://nexdocs.cossanexusholdings.co.za`.
- Cossa Store / online store / ecommerce / digital-products brief resolves `cossa_store` and copies `https://store.cossanexusholdings.co.za`.
- GROWTH platform brief resolves `growth` and copies `https://growth.cossanexusholdings.co.za`.
- Cossa Tech, Construction and Facility Services use their approved configured destination (currently WhatsApp).
- Generic/unclear content falls back to the configured `default` destination.
- Copy full post includes hook, caption, CTA, approved link and hashtags.
- Saved assistant drafts retain the CTA plus approved link and expose a one-click Copy action.
- Recommended posting time and visual idea are not copied into the public post.
