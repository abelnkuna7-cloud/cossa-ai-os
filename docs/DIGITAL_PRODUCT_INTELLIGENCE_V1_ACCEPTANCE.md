# Acceptance cases

## eBook / Storybook
Input: children's eBook/storybook, age 3-7, PDF plus activity book.
Expected: subtype proposal `ebook_storybook`; require evidence-backed creator, publisher, language, audience, genre and page count; never invent ISBN. Existing secure deliverables remain authoritative.

## Course
Input: business course/video training.
Expected: distinguish online/video course; request instructor, level, learning outcomes and relevant module/lesson/duration evidence. Do not invent certificates or credentials.

## Software
Input: downloadable business software.
Expected: subtype `software`; request version, platforms, system requirements and licence evidence. Do not invent compatibility or licence rights.

## Publication diagnostic
If R199 is entered in an unsaved draft while persisted price is absent, show `entered — save draft to persist it`, not `Missing selling price`.

## Regression
Physical, affiliate, POD and dropshipping remain existing top-level types and must not inherit digital-only requirements.

## Production rule
Do not merge until the existing Product Manager route actually consumes these helpers and the existing workforce runtime actually composes the capability additions. Helper modules alone are not a completed customer-facing upgrade.
